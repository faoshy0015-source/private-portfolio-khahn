# HanaV Private Portfolio V1.0

**개인 로컬 검증용 Streamlit 앱**입니다. 하나증권 공식 서비스가 아니며, 고객에게 분석자료를 제공하기 전에는 반드시 사내 보안·전산·준법 및 시장정보 이용조건을 확인해야 합니다. 기존 `HanaV Trading` 파일은 변경하지 않습니다.

## Windows 실행 방법

1. ZIP 압축을 해제합니다.
2. Python 3.11~3.13이 설치된 Windows에서 `run_windows.bat`를 더블클릭합니다. 최초 실행에는 Python 패키지 설치를 위한 인터넷 연결이 필요합니다.
3. 검은 창에서 앱 비밀번호를 입력하고, 브라우저 `http://127.0.0.1:8501`로 접속합니다.
4. 업로드가 없으면 **가상 65종목 데모**가 열립니다. 모든 금액/수량/환율/기준가는 예시이며 실제 고객 데이터가 아닙니다.
5. `samples/portfolio_template.xlsx`에 고객별칭, 종목코드, 보유수량 등 입력 후 사이드바에서 업로드합니다.
6. `Yahoo 공개 종가 조회`를 선택하고 **60종목 일괄 시세 갱신** 버튼을 눌러 조회합니다. 일부 시세가 제공되지 않으면 해당 종목 가격/환산액은 누락으로 표시됩니다.
7. 뉴스 모니터링 또는 종목별 뉴스를 선택하여 공개 RSS를 조회하고, 보고서 탭에서 PDF를 생성합니다.

### 수동 실행

```powershell
cd 경로\HanaV_Private_Portfolio_V1
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:APP_PASSWORD="본인이_정한_비밀번호"
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

## 엑셀 입력양식

| 열 | 설명 |
|---|---|
| 고객구분 | `고객 A`, `고객 B` 등 **익명 별칭** |
| 종목코드 | 국내 6자리 (`005930`), 미국 `NVDA` 또는 `.KS`/`.KQ` 등 Yahoo 티커 |
| 종목명 | 분석 화면에 표기할 회사명 |
| 시장 | `KOSPI`, `KOSDAQ`, `US` (코스닥 종목은 반드시 `KOSDAQ`) |
| 통화 | `KRW` 또는 `USD` |
| 보유수량 | 필수, 0보다 큰 숫자 |
| 매입단가 | 선택, 입력 시 수익률 계산. 분할 반영 단가를 사용해야 함 |
| 기준가 | 선택, **입력 기준가 모드**에서 평가에 활용. 실시간 가격 아님 |
| 업종·종목유형 | 사용자 입력 분류 (`ETF` 등) |
| 목표가·목표가출처·목표가기준일 | 사용자 검증 자료 수동 입력, 없으면 목표가 미표시 |
| 비고 | 내부 작업 메모, 개인정보 금지 |

기준가, 매입단가, 목표가는 **종목의 통화 단위**로 입력해야 합니다. USD 환율 조회가 안 되면 수동으로 입력해야 하며, 환율 없이 USD 자산은 KRW 합산에서 제외됩니다. 실현손익·세금·배당·수수료는 반영하지 않습니다.

## 현재 구현된 기능

- 엑셀/CSV 60종목 이상 업로드, 직접 수정, 고객별칭 필터 및 전체보기
- 국내/KOSDAQ·미국 종목을 USD/KRW로 함께 평가하고 포트폴리오 비중·손익 계산
- 공개 Yahoo Finance 1년 일봉 일괄 조회(요청 시), 20/60/120일 이동평균, 52주 종가 고점대비 및 1/3개월 기간 수익률
- 업종 분류에 따른 비중과 최대 포지션 집중도, 시세/환율 누락 탐지
- Google News RSS 기반 선택 종목 및 다종목 최근 뉴스(요청 시, 실패·오탐 가능)
- 사용자 입력 근거가 있는 목표가·괴리율, **규칙 기반** 관리 모니터링 의견
- 데이터 점검 PDF / CSV 보고서 다운로드
- 로컬 비밀번호 로그인, 메모리 세션 운영, DB 무저장

## 알려진 제한

- V1에는 **AI LLM 자동호출이 없습니다.** 종목별 전략 메모는 규칙 기반이며 자동 매수/매도 추천을 하지 않습니다.
- 과거 HanaV Trading에서 쓰던 개인 KIS 키/호출 로직을 고객용 데이터 제공에 그대로 활용하지 않았습니다. 사용권·내부 승인을 거쳐 차기 버전에 연동할 수 있습니다.
- 목표가는 확인된 **수동 입력자료만** 보여줍니다. 외부 컨센서스 자동수집, 실적 예측, 투자자 수급, 계좌자동연동, ETF 구성종목 전개/중복 분석, 종목별 전체 60건 PDF 심층분석은 아직 없습니다.
- 가격조회가 기본 자동실행되지 않습니다. 제공처 장애·시세 지연·분할/배당 이벤트·환율 미조회 시 평가액이 부정확하거나 누락될 수 있습니다.
- 국내 종목의 거래시장 미기입 시 `.KS` 가정. 코스닥 종목은 시장 `KOSDAQ`을 입력해 `.KQ`로 변환하세요.
- 보고서는 **전체 종목 기본표 + 평가액 상위 10종목의 규칙 기반 설명**을 제공합니다.
- Google News 검색 정확도, Yahoo 가격 정확성 및 제3자 재배포 적법성을 보증하지 않습니다.
- 원화 평가액이 누락된 경우 합계는 일부 자산만 나타내므로 전체 자산 규모로 해석하면 안 됩니다.
- 회사 허가 없이 실제 고객 실명·계좌번호·평단가가 포함된 파일을 공개 Streamlit Cloud, 개인 PC 외부 서비스에 올리지 마세요. 현재 도구는 로컬 파일 없이 세션에만 입력 데이터가 저장되도록 작성됐지만 로컬 PC/브라우저 자체의 보안은 별도 책임영역입니다.

## 구조

```
app.py              Streamlit UI, 파일 업로드, 시세 뉴스 요청, 보고서 탭
core.py             보유종목 검증, 환산 평가, 리스크 점검, 원칙 기반 메모
services.py         공개 Yahoo 금융종가 / Google News RSS
pdf_report.py       로컬 한글 PDF 보고서 생성
samples/            입력 양식 + 가상 65종목 시연 데이터
tests/              핵심 계산 및 보고서 테스트
```

## 데이터 보호 설계

- 고객명/수량/평균단가/자산액은 외부 시세·뉴스 호출 인자로 사용하지 않습니다.
- 네트워크로 전송하는 값은 공개된 `티커` 및 입력 `종목명` 검색어뿐입니다. 따라서 종목명 셀에는 개인정보를 입력하지 마세요.
- 앱은 파일·DB에 고객 정보를 자동 영속 저장하지 않으며, `st.session_state`에만 유지합니다. PDF/CSV 다운로드는 본인이 직접 실행하는 경우에만 생성됩니다.
- 서비스 데이터를 조회하기 위해 URL에 계좌번호 등을 넣지 않습니다.
- 앱 비밀번호 필수이며 기본 비밀번호는 포함하지 않습니다. 비밀번호 로그인은 인증 인프라를 대체하지 않습니다.
